# Audio Book Reader 🎧📖

A lightweight, browser-based web application that uses Optical Character Recognition (**[Tesseract.js](https://github.com/naptha/tesseract.js)**) and live video input to scan, read, and display text from physical books or documents in real-time.

---

## Features

* **Real-Time Video Capture:** Uses your device's camera feed to view text on the fly.
* **In-Browser OCR:** Powered by Tesseract.js to extract text directly from the video stream without requiring server-side processing.
* **Responsive Display:** Formats and displays recognized text dynamically using clean preformatted text areas.

---

## Tech Stack

* **HTML5 / CSS3** for UI structure and layout.
* **JavaScript (ES6+)** for video stream control and OCR integration.
* **[Tesseract.js](https://github.com/naptha/tesseract.js)** for client-side Optical Character Recognition.
